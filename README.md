# 🛒 SQL Superstore Sales & Revenue Analytics

## Project Overview
An end-to-end MySQL analytics project examining over 9,800 transactional sales records to evaluate revenue performance, customer rankings, shipping preferences, and Year-over-Year (YoY) growth trends.

## Tech Stack & SQL Concepts
- **Database:** MySQL Workbench
- **Data Manipulation:** Data Type Conversions (`STR_TO_DATE`), String Cleansing, `ALTER TABLE`, `UPDATE`
- **Analytics Capabilities:** Aggregations (`GROUP BY`, `HAVING`), Window Functions (`DENSE_RANK()`, `LAG()`), CTEs, Subqueries, and Date Formatting (`DATE_FORMAT`).

## Key Insights
- **Top Revenue Categories:** Technology (Phones) and Furniture (Chairs) drive highest overall revenue contribution.
- **YoY Growth:** Strong positive growth recorded in 2017 (+30.64%) and 2018 (+20.30%).
- **Shipping Modes:** Standard Class accounts for over 59% of total company order distribution.
